# AutoOrganize

`AutoOrganize` 是一个用于整理电影和电视剧文件的桌面程序。它根据文件名识别媒体信息，从元数据提供商获取元数据，并按照指定的目录和文件名规则整理文件。

项目目前仍处于早期开发阶段，欢迎大家对此项目进行贡献，也可能会进行重大变更。

## 使用流程

1. 添加需要整理的文件或目录，并选择媒体类型。
2. 等待文件名解析和元数据匹配。
3. 在编辑页面检查识别结果，必要时手动调整。
4. 在设置中选择输出目录、命名模板和文件传输方式。
5. 开始整理，并在结果页面检查成功和失败项目。

TMDB 元数据服务需要可用的 API Key（自带一个API Key，是使用我的账户申请的，请不要用于其他地方），可以在设置中修改。
